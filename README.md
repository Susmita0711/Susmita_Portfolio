# Susmita Hazra — Portfolio

A modern, dark-themed portfolio website built with React and Vite.

**Live:** [susmitahazra.netlify.app](https://susmitahazra.netlify.app)

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS (CDN)

## Features

- Responsive design (mobile + desktop)
- Dark mode UI
- Typing animation on hero section
- Mouse-follow glow on profile image
- Animated tech stack marquee
- Project flip cards
- Blog article reader
- Smooth scroll navigation

## Getting Started

```bash
npm install
npm run dev
```

The dev server runs on `http://localhost:5173`
